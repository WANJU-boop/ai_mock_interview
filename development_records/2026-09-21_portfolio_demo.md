# 首次桌面运行、报告预览与项目展示

## 目标

让访客看到真实软件界面，完成无密钥演示并直接查看面试结果。
提供英文首页、独立中文说明、首次构建步骤和约 30 秒图文演示。

## 核心数据流

Qt 开始按钮 → worker → Mock 出题与预设回答 → 编排评分 → 原子保存 JSON →
主线程接收报告路径 → 查看报告 → 有大小上限地读取文件 → 纯文本预览。

报告查看功能已接入主流程，不是孤立的展示页面，也不会重新请求在线服务。

## 实测发现的首次运行问题

从桌面启动时，当前工作目录可能不可写。旧 Logger::Init 捕获文件 sink 异常后
留下空指针，面试线程第一次写日志时崩溃。终端测试目录可写，因而没有触发问题。

修复：日志文件创建失败时保留控制台 logger；Qt 入口改用 QStandardPaths 的
应用数据目录。新增冷启动日志失败回归测试，避免再次被懒初始化掩盖。

## C++ 与 Qt 知识点

- 资源初始化失败必须保持对象可用或明确抛错，不能吞掉异常后留下空指针。
- Qt 的父子对象关系管理报告窗口生命周期，关闭时自动释放。
- QPlainTextEdit 只展示文本，不解释候选人答案中的 HTML。
- 报告读取限制为 4 MiB，并检查结构和分数范围；损坏文件显示明确错误。
- worker 继续负责阻塞外部服务，主线程只显示已经生成的本地结果。
- 中文注释覆盖公开入口、日志失败回退、报告边界和新增测试意图。
